# MyTab ✨ Эстетичное Расширение Новой Вкладки (с Синхронизацией WebDAV и Git)

Минималистичное, стильное и ориентированное на конфиденциальность расширение для Новой Вкладки (New Tab) браузера с эффектом матового стекла (Glassmorphism), динамическим адаптивным контрастом и плавной сменой темной и светлой тем. Полностью совместимо с **Google Chrome (MV3)**, **Microsoft Edge**, **Mozilla Firefox** и всеми браузерами на базе Chromium.

- 🔗 **Репозиторий GitHub**: [https://github.com/Troray/MyTab](https://github.com/Troray/MyTab)
- 🦊 **Магазин Firefox Add-ons**: [Официальная страница Firefox Add-ons](https://addons.mozilla.org/zh-CN/firefox/addon/mytab-%E6%9E%81%E7%AE%80%E6%96%B0%E6%A0%87%E7%AD%BE%E9%A1%B5/)
- 🌐 **Магазин Microsoft Edge Add-ons**: [Официальная страница Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/bchchngjdocafdpnnoiolnbfdnkngfjn)
- 🐛 **Сообщить об ошибке или предложить идею (Issues)**: [Issues](https://github.com/Troray/MyTab/issues)

## 🌟 Ключевые Возможности

- 📱 **Карусель Нескольких Рабочих Столов и Жесты (v1.3.0)**: Архитектура рабочих столов на физическом движке Embla Carousel. Плавное перелистывание мышью или стрелками клавиатуры, с плавающими индикаторами страниц из матового стекла. Переименование столов, безопасное удаление с автоматическим переносом ссылок и независимая память категорий.
- 🔖 **Быстрый Импорт Закладок без Дубликатов (v1.3.0)**: Моментальное считывание стандартных закладок из Chrome, Edge и Firefox, а также файлов HTML Netscape (Safari и др.). Визуальное дерево выбора, интеллектуальное сглаживание папок, сравнение дубликатов в реальном времени и предварительная статистика.
- 🔒 **Приватное Пространство в Двойном Контейнере (v1.2.0)**: Физическое разделение повседневного серфинга (Основное Пространство) и конфиденциальных страниц (Приватное Пространство). Автоматически активируется в режиме инкогнито или на странице `private.html`.
- 📌 **Быстрое Добавление в Одно Нажатие с Панели Инструментов (Popup)**: При просмотре любого сайта нажмите значок на панели браузера, чтобы мгновенно сохранить заголовок, URL и фавикон высокого разрешения в нужное пространство и категорию.
- 🎨 **Режим Чистых Значков и Глубокая Настройка (v1.3.0)**: Стильное отображение в виде значков мобильного экрана с поддержкой карточек из матового стекла. Индивидуальная настройка цвета для **6 главных элементов** (часы, дата, приветствие, строка поиска, категории и карточки сайтов) с автоанализом яркости Canvas.
- 📅 **Лунный Календарь и Традиционные 24 Сезона (v1.2.0)**: Встроенный легкий лунный алгоритм с элегантным отображением в заголовке и отдельным переключателем.
- 🖼️ **Коллекция Обоев и Плавное Переключение**: Ежедневные HD-обои Bing и фотографии Unsplash (через CDN) с плавным угасанием с двойной буферизацией без мерцания экрана.
- ⚡ **Умный Поиск Фавиконов и Векторные Иконки**: Многоканальный алгоритм получения иконок с локальным кэшированием Base64. Если иконка не найдена, автоматически генерируется цветная векторная SVG-иконка по первой букве домена.
- 🛡️ **Перехват Ошибок в Матовом Стекле (ErrorBoundary)**: Перехватывает непредвиденные ошибки во время выполнения с помощью элегантного окна с функцией быстрой перезагрузки и сброса кэша.
- 🗂️ **Управление Категориями и Сортировка Drag & Drop**: Удобная группировка с плавным перетаскиванием и встроенным редактированием.
- 🔍 **Умный Мультипоиск**: Быстрое переключение между Google, Bing, Baidu, DuckDuckGo, Yandex и GitHub. Нажмите клавишу `/`, чтобы мгновенно сфокусироваться на строке поиска.
- 🐙 **Синхронизация через Git (GitHub / Gitee)**: Режимы **Secret Gist (полностью автоматически по одному токену)** и **личный Git-репозиторий** с умным слиянием версий по меткам времени.
- ☁️ **Синхронизация через WebDAV**: Подключение к домашним серверам Synology NAS, Nextcloud, ownCloud, Alist и Jianguoyun.
- 🔐 **Безопасное Резервное Копирование**: Экспорт и импорт в формате JSON с автоматическим скрытием токенов и данных приватного пространства.
- 🌐 **Полная Локализация на 13 Языков**: Русский, Английский, Немецкий, Французский, Испанский, Итальянский, Португальский, Польский, Турецкий, Японский, Корейский и Китайский (Упрощенный/Традиционный).

### Способ 1: Официальные Магазины Расширений (Рекомендуется)

| Браузер | Ссылка на Магазин | Статус |
| :--- | :--- | :--- |
| **Microsoft Edge** | 🌐 [Установить из Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/bchchngjdocafdpnnoiolnbfdnkngfjn) | ✅ Доступно |
| **Mozilla Firefox** | 🦊 [Установить из Firefox Add-ons](https://addons.mozilla.org/zh-CN/firefox/addon/mytab-%E6%9E%81%E7%AE%80%E6%96%B0%E6%A0%87%E7%AD%BE%E9%A1%B5/) | ✅ Доступно |
| **Google Chrome** | 🟡 Ожидает модерации в Chrome Web Store | 🚀 Доступна ручная установка |
| **Другие Браузеры Chromium** (Brave, Vivaldi и др.) | 📦 Скачать `chrome.zip` со [страницы GitHub Releases](https://github.com/Troray/MyTab/releases) | 🚀 Доступна ручная установка |

---

### Способ 2: Офлайн-установка (Chrome и браузеры на базе Chromium)

1. Откройте [страницу релизов GitHub Releases](https://github.com/Troray/MyTab/releases), скачайте последнюю версию архива `chrome.zip` и распакуйте его в постоянную папку на компьютере.
2. Откройте браузер и перейдите на страницу управления расширениями:
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
   - **Brave**: `brave://extensions/`
3. В правом верхнем углу включите переключатель **«Режим разработчика» (Developer mode)**.
4. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение» (Load unpacked)** и укажите распакованную папку.

> 💡 **Совет**: Не перемещайте и не удаляйте распакованную папку после завершения установки.

---

### 📌 Рекомендуется: Закрепить значок на панели инструментов

1. Нажмите на **значок расширений (деталь пазла 🧩)** в правом верхнем углу браузера.
2. Найдите **MyTab** и нажмите значок **булавки 📌 (Закрепить)**.
3. Это позволит сохранять веб-страницы в один клик и мгновенно открывать Приватное Пространство в окнах инкогнито.

## ☁️ Руководство по Облачной Синхронизации и Резервному Копированию

### 1. Синхронизация через WebDAV (Synology NAS / Nextcloud / Alist / Jianguoyun)

| Провайдер | Пример URL Сервера | Имя пользователя | Пароль / Токен приложения |
| :--- | :--- | :--- | :--- |
| **Nextcloud / ownCloud** | `https://vash-domen.ru/remote.php/dav/files/USER/` | Имя пользователя | Пароль или токен приложения |
| **Synology NAS WebDAV** | `https://nas-ip:5006/` | Учетная запись NAS | Пароль NAS |
| **Alist** | `https://vash-domen-alist.com/dav` | Учетная запись Alist | Пароль Alist |
| **Jianguoyun** | `https://dav.jianguoyun.com/dav/` | Зарегистрированный email | Пароль приложения |

- Откройте «⚙️ Настройки -> Синхронизация -> WebDAV», заполните данные и нажмите **Проверить подключение**.
- Вы можете создать или восстановить резервную копию в любое время, а также включить автосинхронизацию при изменениях.

### 2. Синхронизация через Git (GitHub / Gitee)

#### Вариант A: Secret Gist (Самый простой)
Требуется только токен:
1. **Создание Токена**:
   - **GitHub**: Используйте ссылку в настройках для создания Personal Access Token с разрешением **`gist`**.
   - **Gitee**: Создайте персональный токен с разрешением **`gists`**.
2. **Автоматическая Настройка**:
   - Вставьте токен в «⚙️ Настройки -> Синхронизация -> Git» и нажмите **Проверить / Автонастройка**. Выделенный Secret Gist (`mytab-backup.json`) будет создан автоматически.

#### Вариант B: Личный Git-репозиторий (Режим Repo)
1. **Токен**: Создайте токен с разрешением **`repo`** (GitHub) или **`projects`** (Gitee).
2. **Автосоздание**: Введите название репозитория и нажмите **Проверить и подключить**. Если репозиторий не существует, он будет автоматически создан через API.

## 🔒 Руководство по Приватному Пространству (Private Space)

| Параметр | Основное Пространство (Default) | Приватное Пространство (Private) |
| :--- | :--- | :--- |
| **Назначение** | Работа, учеба, публичные демонстрации | Личные закладки, конфиденциальные сайты |
| **Запуск** | Новая вкладка в обычном окне | **Сочетание клавиш `Alt + M`** (Mac: `Option + M`) |
| **Хранилище** | Локальный раздел `default` | Локальный раздел `private` (физически изолирован) |
| **Обои и Сетка** | Независимая тема и карточки | Полностью отдельная память обоев и карточек |
| **Синхронизация**| WebDAV / Git автоматически | **Защита**: Настраивается отдельно |
| **Экспорт** | Обычный полный экспорт | **Скрыто по умолчанию**: Только при установленной галочке |

---

### ⚙️ Включение в Режиме Инкогнито

- **Google Chrome / Microsoft Edge / Brave**:
  1. Перейдите по адресу `chrome://extensions/`.
  2. В карточке MyTab нажмите **Сведения**.
  3. Включите тумблер **Разрешить использование в режиме инкогнито**.
- **Mozilla Firefox**:
  1. Откройте `about:addons` и выберите **MyTab**.
  2. В пункте «Запуск в приватных окнах» выберите **Разрешить**.

## 🛠️ Локальная Разработка и Сборка

```bash
# 1. Клонирование репозитория и установка зависимостей
git clone https://github.com/Troray/MyTab.git
cd MyTab
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Сборка расширения
npm run build
npm run package # (Опционально) Создать zip-архивы
```

Готовые файлы будут в папке `dist/`:
- `dist/chrome/`: Для Chrome, Edge, Brave и др.
- `dist/firefox/`: Для Firefox

## 🔒 Разрешения и Конфиденциальность

- **`storage` / `unlimitedStorage`**: Локальное сохранение закладок, категорий, настроек и кэша иконок.
- **`bookmarks`**: Локальное считывание закладок только при импорте (никаких внешних отправок данных).
- **`alarms`**: Фоновый триггер для периодической автосинхронизации.
- **`activeTab`**: Получение заголовка и URL при клике на значок расширения.
- **`host_permissions (<all_urls>)`**: Получение фавиконов и прямое соединение с серверами WebDAV или Git.
- **Полная конфиденциальность**: Мы не отслеживаем и не собираем ваши данные. Подробнее в [PRIVACY.md](../../PRIVACY.md).
